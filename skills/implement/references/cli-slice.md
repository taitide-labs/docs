# 命令行垂直切片实现

对照主干冻结命令契约与黑盒验收测试，在隔离 `Worktree` 内完成单个命令行垂直切片并激活其命令入口。

## 读写边界划分

- 冻结只读区：`primitives`、`contracts`、全局共享命令参数定义及既有黑盒验收测试断言（仅允许移除工单显式授权取代的旧规则场景）。
- 切片自治区：目标子命令模块目录、对应端口适配器与单元测试，以及移除目标命令行验收场景上的 `wip` 跳过标记（及工单授权取代的旧场景）。

## 执行步骤

1. 对齐命令基线：读取目标 GitHub Issue、所属上下文 `context.md`、冻结命令契约与黑盒验收测试场景；严禁在命令帮助文本、提示信息与错误输出中使用 `context.md` 中声明避免的混用词汇，必须严格对齐统一语言。
2. 实现子命令逻辑与输出规范：
   - 遵循 `clig.dev` 规范实现参数解析与核心流程，严格隔离 `stdout` 结构化数据（含 `--json` 等机器可读模式）与 `stderr` 诊断输出，规范退出码语义并支持非交互管道与静默模式。
   - 激活该子命令入口注册状态。
3. 补齐单元测试与激活验收测试：补齐脱离外部网络的单元测试，移去目标黑盒验收测试场景上的 `wip` 跳过标记，确认子命令路由、退出码及 `stdout` 与 `stderr` 流隔离全部通过。
