# 客户端与命令行切片实现

对照冻结表面基线与契约定义，在隔离 `Worktree` 内完成图形界面或命令行垂直切片及回归验证。

## 读写边界划分

- 冻结只读区：严禁在切片分支内私自篡改 `contracts`、`Feature Map` 约定的核心导航坐标、基础 `Design Tokens` 语义定义或既有 `Golden Snapshot` 的非本切片基线。
- 切片自治区：读写范围限定于目标页面目录或子命令模块、对应切片解耦状态层与端口适配器、无头交互与无障碍行为测试，以及受本切片需求授权变更的快照与冒烟测试用例。

## 执行步骤

1. 对齐交互基线：读取目标 GitHub Issue、所属上下文 `context.md`、`Feature Map` 词汇定义及阶段 2 接口模型，严禁在界面层使用 `context.md` 中声明禁止的混用词汇。
2. 实现界面或命令表面：
   - 图形客户端优先复用已建立的无状态基础组件与 `Design Tokens` 语义变量，通过解耦状态层对接抽象客户端端口或原型桩数据，同步维护无障碍标签与键盘焦点流转。
   - 命令行切片遵循 `clig.dev` 规范严格隔离 `stdout` 结构化数据与 `stderr` 诊断输出，规范退出码语义与静默模式支持。
3. 执行表面验证与基线比对：补齐脱离网络的单元测试与无头行为测试；涉及视觉布局或交互路径变更时在真实渲染窗口复跑交互走查并比对亮暗双主题 `Golden Snapshot` 基线。
