# 客户端与交互设计

在投入高成本后端战术开发前，基于阶段 2 契约直接构建生产级客户端界面（或可执行命令行应用），以真实可点击的交互体验低成本验证产品需求与多端视觉标准。当交付纯后端服务或无界面领域平台时，核对阶段 2 契约完备后显式说明跳过本阶段，经用户确认后直接进入阶段 4。

## 图形客户端执行流程

1. 对齐并落盘 `DESIGN.md`：明确应用支持的目标平台家族集合（桌面与桌面 Web、移动端、终端 TUI）、核心用户任务与具象视觉参照物（避免“现代简约”等空泛形容词），在客户端根目录（单包项目在仓库根目录）落盘 `DESIGN.md`；当关键页面布局结构存在未决分叉时，先在同一路由挂载 2-3 个结构迥异的变体供对比拍板，定稿后清理临时变体。
2. 建立令牌材质、多端自适应 `ui/` 层与 L0 静态守卫：落盘亮暗对称的语义色令牌与表面材质（顶光高光、内凹阴影、浮层质感成对定义）；在无样式行为原语（焦点管理、键盘导航与无障碍角色投影）之上封装内聚了各目标平台密度与形态变形（如桌面锚定浮层在移动端自动变形为底部抽屉或独立子页、触控端补足最小点击热区）的共享 `ui/` 受控组件层及全状态展厅（Gallery）；同步建立 L0 静态守卫测试，扫描拦截业务层硬编码裸色值或内联样式覆盖，并校验亮暗主题键值完全对称。
3. 编写生产协议调用层并组装可交互页面：
   - 严禁在业务页面直接编写裸色值、裸字号圆角或绕过 `ui/` 层手搓控件，必须仅组合 `ui/` 受控组件与布局原语（内边距归组件自身、间距归父容器、避免双倍内边距；领域状态归 `store`，瞬态草稿归页面，虚拟长列表复用行状态按稳定领域 ID 外置；需主线程即时响应的禁用或关闭拦截约束预先声明为状态属性）。
   - 客户端直接按阶段 2 契约编写生产级协议请求与 RFC 9457 错误解析代码，仅在底层网络传输层挂载覆盖正常流、空态、加载态、慢请求竞态与业务错误的确定性拦截桩（后续后端上线仅需切换环境配置连接真实服务，无需重写客户端调用层；超大型应用优先完成核心主链路页面闭环以确认需求，大量同质长尾子页面可留至阶段 5 拆单并行补齐）。
4. AI 真实窗口自验闭环：启动本地开发宿主，使用浏览器、桌面或终端自动化工具逐条操作业务流、切换亮暗双主题与各目标平台视口（桌面宽窗、手机竖屏、终端字符网格），结合无障碍树与本地临时截图（不提交入库）自查控制台零报错、对齐脊线一致、外置焦点环无裁切、无横向溢出与遮挡，自行修复全部缺陷后再呈交用户。
5. 用户实机点按确认：交由用户在真实运行环境中点按体验并确认业务需求与多端交互；若实测暴露流程别扭或字段遗漏，当场低成本回修界面并同步修订阶段 2 契约（乃至阶段 1 术语），在用户最终拍板前不提前编写重度行为测试以免返工。
6. 固化客户端自动化测试网：待用户拍板定稿后，补齐 L1 `store` 纯状态单测与 L2 无头交互验收测试（注入传输拦截桩、内存存储与手动时钟零等待快进；严禁绑定内部节点层级或导出私有状态供测试读取，必须仅使用无障碍角色、标签或可见文本语义选择器定位元素；覆盖主流程、空态/加载/错误/断网、慢请求竞态不覆盖新结果、返回栈状态保留、长列表滚动复用与多端视口尺寸切换），供本地与 CI 常态化极速执行，后续无界面变更无需重复触发视觉截图。

## 独立命令行工具执行流程

1. 遵循 clig.dev 规范编写真实命令解析入口并在底层传输或数据源挂载确定性桩，冻结正交的一级动作与二级对象子命令层次、帮助文案、非交互静默模式、退出码契约以及 `stdout` 结构化数据与 `stderr` 诊断流隔离；严禁将某个二级子命令专有的局部参数提升为全局顶层选项，必须将其限定在对应子命令作用域内。
2. AI 先实际执行命令自检帮助输出、正常流、错误退出码与管道静默模式无误后交由用户实操确认需求，敲定后固化命令行冒烟测试。

## `DESIGN.md` 模板

```markdown
# <应用名称> 设计规范

<1-2 句话写明支持的目标平台家族集合（桌面与 Web / 移动端 / 终端 TUI）、核心用户任务与具象视觉参照物，不使用空泛形容词>

## 设计原则

- <3-4 条可检验的层级、密度与克制度准则，如依靠字阶、分割线与表面深度建立层级而非色块填充>

## 色彩与表面材质

- 令牌事实源：<指向代码中的主题令牌与表面材质文件路径；下文仅引用语义令牌名，不抄写具体色值或像素>
- 色阶与强调色：<页面底色、卡片、内凹区、凸起区的明暗递进关系，以及单一主强调色与状态色的允许作用范围>
- 表面材质：<卡片、内凹槽、凸起控件与浮层在亮暗主题下的顶光高光、边框、阴影与毛玻璃成对规则>

## 排版、空间与多端适配

- 字体与排版：<标题、正文、等宽辅助标签的层级职责及中西文标点与字距规则>
- 空间与对齐：<容器尺度、间距语义关系、内边距归组件与间距归父容器约束、同心圆角及共享对齐脊线>
- 跨平台家族映射：<桌面指针紧凑密度与多栏常驻导航、移动端最小触控热区与导航栈/底部抽屉变形、终端整格字符对齐的适配规则>

## 共享控件目录

- <列出 `ui/` 层受控组件、语义变体（`variant` / `size`）及完备交互态（常规、悬停、按压、展开、焦点环、选中、禁用、加载、错误）与键盘无障碍契约；页面层仅负责布局摆放与选变体>

## 页面拓扑、命令与文案

- 壳层与页面地图：<全局导航壳层结构、各路由页面坐标与核心用户任务>
- 命令与文案规范：<主按钮、菜单、快捷键多入口同源规则，上下文经济文案原则及二次弹窗省略号 `…` 约定>

## 动效清单

- <前置列出页面与控件状态切换对应的动画方式、时长曲线令牌及 `prefers-reduced-motion` 降级行为>

## Do's and Don'ts

- Do: <必须贯彻的标志性视觉与交互做法>
- Don't: <明确禁止的廉价套路或越界做法>
```
