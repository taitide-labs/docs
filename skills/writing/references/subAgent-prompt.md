# subAgent Prompt 规范

派发给 subAgent 的 Prompt 追求精准与简洁，无需像向人类交代任务那样事无巨细；subAgent 同样具备工具与 Skill 调用能力，严禁冗余复制已有资产，应当使用指针引用。

优先按照 SMEAC 模型派发任务；当任务产出仅回传给调用方阅读、不直接面向用户时，优先使用英文编写 Prompt。

常规任务直接按 SMEAC 派发，若是调研类任务注意以下前提：

- 当派发开放式调研任务时，严禁预设解法，应当聚焦背景与目标，以免受限于过时的先验知识而框住调研范围。
- 当派发专项调研任务（如深入研究某个项目）时，必须确保目标准确，而非从先验知识中推断；当目标不确定时，应当先通过搜索工具收集信息，再派发 subAgent 深入研究。
